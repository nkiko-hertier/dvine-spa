# D'Vine Spa

Monorepo for the D'Vine Spa booking system.

```
backend/     Node.js/TypeScript API — see backend/README.md
frontend/    (coming soon)
```

## Backend

```bash
cd backend
cp .env.example .env
npm install
docker compose up -d
```

Full setup, architecture, and API reference: [`backend/README.md`](backend/README.md), [`backend/docs/API_DOCUMENTATION.md`](backend/docs/API_DOCUMENTATION.md). Build plan / progress: [`backend/docs/task.md`](backend/docs/task.md).
